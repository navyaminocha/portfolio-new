## Getting Started

To run the portfolio locally, clone the repository:

```bash
git clone https://github.com/navyaminocha/portfolio-new.git
```

Navigate to the project directory:

```bash
cd portfolio-new
```

If the application is inside the `portfolio` directory:

```bash
cd portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

*The commands above assume the project uses a Node.js-based framework such as Next.js and has the corresponding scripts in `package.json`.*
